# J&R Motos

Site da J&R Motos, serviço de guincho de motos 24 horas e frete com pick-up em Sorocaba (SP) e região.

É uma página única que apresenta os serviços e leva o visitante a chamar a empresa pelo WhatsApp, com a mensagem já preenchida.

## Funcionalidades

- Apresentação dos serviços de guincho e frete.
- Formulário que monta o pedido e abre a conversa no WhatsApp.
- Topo animado com a foto da pick-up e efeito de giroflex feito em CSS.
- Metadados para SEO e pré-visualização do link em redes sociais.

## Tecnologias

- HTML, CSS e JavaScript puro, sem framework, sem build e sem banco de dados.
- Fonte Archivo auto-hospedada (licença SIL Open Font).
- Hospedagem na [Vercel](https://vercel.com).

## Estrutura

```
index.html   o site inteiro (conteúdo, estilo e scripts)
assets/      imagens
fonts/       fonte Archivo
vendor/      biblioteca de animação
frames/      quadros de uma versão anterior do topo (não publicados)
```
